ABOUT THE SYSTEM
- Need to create an account for admin since the login page is shared for both user and admin.
- The admin is only one so you can optionally create in database or in seeder.
  
*LOGIN PAGE*
- when the user have already existing account it can proceed to the system directly
- the user required to register if he doesn't have yet an account

*ADMIN VIEW*
-Dashboard
  - Can see the count of all the task per status of all tasks of all members also the visual distribution of it and recent tasks list 
-Tasks
  - The admin has the access in creating new task, updating and editing a task and deleting it as well
- Members
  - The admin has the access in creating new member, updating and editing a member and removing it too.
- Notifications
   - The admin can be notify if a user update the status of his assigned tasks
   - The admin can be notify if an assigned status is overdue
   - The admin can be notify if a user send the task assigned by the admin
 
  *USER VIEW*
  -Dashboard
    - Can see the Can see the count of all the task per status of all tasks of a member also the visual distribution of it and recent tasks list
  -Tasks
    - The user can see the task assigned to him/her by the admin
  -Notifications
    - The user will be notify if the admin assign new task for him
    - the user will be reminded by the system before the deadline of the tasks starting 3 days before the deadline.
